# v0.1.3 — отображение и навигация Steam

- Iframe получает максимальный слой, чтобы Decky route/Steam root не перекрывал внешний iframe, оставленный в DOM без переноса.
- Steam навигация выполняется до закрытия Side Menus. Decky Router отдельно предписывает этот порядок: обратный порядок может скрывать overlay и отменять маршрут.
- Пополнение по-прежнему использует исходную форму по центру; внешняя платёжная страница следует штатному Steam Navigation.

Базовая проверка v0.1.2 Chromium охватывает embedded bridge и layout. Повторная проверка на Deck необходима: Steam navigation APIs и панели поверх Steam проверяются на целевом устройстве.
