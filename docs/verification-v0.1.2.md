# v0.1.3 — отображение и навигация

## Исправления

- Убраны всплывающие сообщения из UI. Ошибка пользовательского действия отображается в панели; фоновые focus-запросы больше не создают циклы ошибок и уведомлений.
- Убраны служебные полосы кнопок сверху и снизу. B — назад, X — ввод в выбранное поле. Пополнение сохраняет исходный viewport 378×322, центрируется и масштабируется до 1.35×. Iframe отображается поверх контейнера Steam. Навигация вызывается до закрытия боковых меню Steam, чтобы меню не отменяло переход. Суммы, комиссии и платёжная логика остаются исходными.
- Iframe остаются дочерними элементами одного контейнера всю жизнь. Для размещения над страницей маршрута меняются координаты через ResizeObserver, а не родитель DOM. В Chromium перенос перезагружал документ и терял состояние формы.
- Сохраняются размеры attach-popup, исправлен формат embed-рукопожатия (__sbEmbed, type).
- Мост подключается к отдельным iframe targets через Target.setAutoAttach. Для текущего документа и следующей навигации устанавливается API; позднее подключение сообщает сайту событием sb:embed. Ошибка исчезнувшего контекста не останавливает обработку остальных событий.

## Проверки

37 тестов Python, 14 TypeScript/DOM; проверка типов и Rollup — успешно.

`pnpm test:browser` запускает отдельный Chromium с принудительной изоляцией сайтов. Реальный Python CDP-мост подключается к iframe точного origin steambalance.cc с локально подменённым тестовым содержимым. Проверяются обнаружение API сайтом, getSteamId через binding, перезагрузка iframe, сохранение введённого значения при hide/show и геометрия карточки. Отдельно загружается исходный HTML пополнения из vendor для визуальной проверки. Внешние платежи и данные аккаунта не используются.

Steam Deck: требуется проверка управления и внешнего вида пользователем. Живой сценарий оценки аккаунта целиком и платежи на устройстве не выполнялись.
