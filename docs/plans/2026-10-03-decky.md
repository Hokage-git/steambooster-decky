# SteamBooster Decky Implementation Plan

**Goal:** Publish a standalone Decky plugin with original catalog, valuation, topup and offers.
**Architecture:** React QAM panel and Python CDP backend reuse pinned JS bundles. The plugin owns its connections and unloads its injections.
**Tech Stack:** @decky/ui, @decky/api, Python asyncio/aiohttp, unittest, pnpm/Rollup.

- [ ] Add failing tests in tests/test_cdp.py for session correlation, events, timeouts, close and local-only websocket URLs. Implement backend/cdp.py; run python -m unittest discover -s tests -v.
- [ ] Add tests/test_policy.py for exact origin, method arguments and delegate routing. Implement backend/policy.py. Retain request limits and unknown-result semantics.
- [ ] Pin Linux source commit 0b462bb853acb54540c1d65a68cac2f6061f9e06 in vendor/manifest.json; scripts/sync_vendor.py copies built framework/plugins, preserves licenses and generates existing bootstrap/website scripts.
- [ ] Add tests/test_runtime.py and tests/test_website.py for target selection, ownership, context invalidation, duplicate bindings and unload. Implement backend/runtime.py, backend/website.py and main.py with generation-scoped tasks, native network/config/bus routing and automatic reconnect.
- [ ] Test route allowlist in tests/actions.test.ts; implement src/actions.ts and src/index.tsx. Native Decky focusable buttons invoke existing Steam website flows and show actionable status. Run pnpm exec tsc --noEmit and pnpm build.
- [ ] Test archive layout in tests/test_release.py; implement scripts/build_release.py, CI and README. Build ZIP plus SHA256SUMS, verify vendor hashes and live read-only transport. Record hardware limitations.
- [ ] Commit, create Hokage-git/steambooster-decky, push main, publish v0.1.0 as a preliminary release with ZIP and checksums.

Device acceptance: Game Mode panel/controller focus, catalog search, valuation, store offers, account switch, sleep/wake, Steam restart, unloading. Hardware checks remain pending until a Deck is available.
