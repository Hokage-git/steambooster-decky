# v0.1.5 — интерфейс Steam Deck

## Изменения

- Вместо закреплённого баннера магазина — одна компактная кнопка пополнения рядом с навигацией. Исходная ссылка каталога сохранена.
- Каталог, оценка и платёжные URL открываются через браузер Steam; локальная форма пополнения остаётся в Decky.
- Предложения добавлены в раздел вариантов покупки игры. Видны издание, регион и цена. Сравнение со Steam допускается только при совпадении пакета и рублёвой цены.
- Панель Decky стала компактнее: действия, короткое состояние, раскрываемые настройки. Промоблок в пополнении убран.
- Касание поля или A вызывает клавиатуру Steam. Текст поступает прямо в исходное поле, расчёт обновляется без дополнительного редактора. Форма освобождает место клавиатуре.
- Исправлена передача выбранного элемента между касанием и контроллером, восстановление фокуса после закрытия клавиатуры.
- Сохранено повторное открытие последней платёжной ссылки без создания второго заказа.

## Проверки

Пройдены TypeScript, production build, 33 Node-теста и 38 Python-тестов, две проверки Chromium. Интеграционный тест использует настоящий framework и checkout: запрос предложений проходит через разрешения scoped-плагина, native bus и исходный HTTP-сборщик с подставными ответами.

Автоматические проверки покрывают навигацию и её ошибки, управление полями, исходный сборщик аккаунта, адаптер предложений и ограничения транспорта. Chromium использует оригинальную HTML-форму checkout с подставными ответами расчёта и создания заказа: сумма изменяется на 250, заказ получает эту сумму один раз. Макеты проверяются при 1280×800 и 800×600.

## Границы проверки

Физический Steam Deck недоступен. Обнаружение клавиатуры сверено с локальным кодом Steam; её фактическое открытие, управление Game Mode и QR платёжного провайдера требуют проверки на устройстве. Реальных покупок, оплат и отправки оценки не было. Тест сборщика аккаунта подтверждает работу с тестовыми данными, но не доказывает исправление конкретного сбоя кнопки на действующем событии сайта.

См. [проверку устройства](device-test.md). Сборка распространяется для проверки на Steam Deck; автоматические тесты не заменяют проверку стабильности на устройстве.
