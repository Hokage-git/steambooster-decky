# v0.1.1: Game Mode и кнопки магазина

## Причина и изменение

Decky выбирает SharedJSContext как один из допустимых GamepadUI-контекстов (официальный `decky_loader/injector.py`, `tab_is_gamepadui`). Наш поиск явно исключал его. Регрессионный тест воспроизводил `decky: frontend not ready` при наличии маркера в SharedJSContext.

Теперь поиск включает этот контекст. При совпадении с Main framework внедряется один раз с host-флагом `deckyCombined`; shared-relay и Main API используют общий lifecycle. Фильтр UI-команд оставляет обработку окон адаптеру Decky. Раздельные контексты по-прежнему поддерживаются.

Store получает панель каталога, оценки и пополнения через CDP binding. Принимаются только три заданные команды из живого default-контекста точного origin Steam Store. При навигации контекст удаляется, при выгрузке удаляются DOM, observer и binding. Исходные web-плагины по-прежнему внедряются для предложений покупки.
