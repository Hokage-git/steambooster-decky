# v0.1.4 — пополнение и удобство на Deck

## Изменения

- Исправлена отмена платёжного перехода: оригинальный checkout открывает внешний URL, затем отправляет `popup-hide`. Раньше активным оставалось пополнение и его скрытие вызывало `NavigateBack`, отменяя переход. Теперь владение маршрутом сбрасывается перед открытием браузера.
- Подтверждение успешного открытия отправляется после вызова навигации. Синхронная ошибка возвращает только отрицательный ответ и восстанавливает видимость формы.
- Последняя платёжная ссылка доступна в панели. Повторное открытие не вызывает API создания заказа. Ссылка сохраняется до переподключения/выгрузки; подтверждение оплаты по ней не определяется.
- Iframe создаётся в документе GamepadUI, найденном через Decky Router/findSP, и слушает события своего окна. Код Decky может исполняться в SharedJSContext; его глобальный document не обязательно отображается на экране.
- Пополнение получило отдельную тему для Deck: крупные поля и кнопки, читаемые суммы, фокус и подсказка управления. Размер адаптируется к экрану. Расчёты, способы оплаты и отправка заказа остаются в закреплённом оригинальном компоненте.
- Панель разделена на баланс, игры/аккаунт и настройки подключения. Добавлены иконки действий, карточка состояния и встроенное сообщение об ошибке. Недоступные действия блокируются до готовности.
- При вводе текста iframe временно скрывается, чтобы не закрывать поле Decky. Подсветка контроллера снимается с предыдущего элемента.

## Проверки

- TypeScript typecheck и production Rollup build.
- 17 Node tests: адаптер, оригинальные компоненты, управление, порядок открытия оплаты и обработка исключения.
- 37 Python tests: CDP, жизненный цикл, мост сайта, ограничения запросов и ZIP.
- Chromium с изолированным профилем: cross-process iframe, обнаружение API, RPC тестового Steam ID, повторная загрузка, сохранение состояния формы.
- Реальный Svelte HTML из закреплённого checkout: макет 1280×800 и 800×600, выбор метода, нажатие Pay с подставными ответами calc/add. Последовательность original main-shell «открыть → скрыть» воспроизведена через production DeckyRelay/PageNavigation. Повторное открытие URL не создаёт второй заказ.

Регрессионные тесты навигации и подсветки воспроизводили сбой до соответствующих исправлений. Старое предположение теста о первом сообщении в очереди заменено поиском конкретного ответа открытия.

## Границы проверки

Chromium-тест подменяет Steam Navigation записью URL; фактический переход Game Mode и QR платёжного провайдера требуют Steam Deck. Реальные заказы и платежи не выполнялись. Макет проверен на тестовых данных. Кнопки Decky используют штатные компоненты, их окончательный вид/фокус также проверяется на устройстве. См. [проверку устройства](device-test.md).
