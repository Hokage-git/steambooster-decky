# Проверка Steam Deck

Версия: v0.1.5. Запишите модель Deck, версию SteamOS, канал Steam и версию Decky. Приложите текст ошибки и действия, которые к ней привели; ключи и платёжные данные не нужны.

- [ ] Установка ZIP из GitHub Releases завершилась, плагин появился в панели Decky.
- [ ] В игровом режиме состояние меняется на «Готов к работе», Steam ID в настройках подключения совпадает с текущим аккаунтом.
- [ ] Каталог открывается; работает поиск, фильтры, прокрутка, направления/A/B, штатная клавиатура браузера Steam.
- [ ] Кнопка покупки в карточке открывает оригинальный сценарий; обычная ссылка карточки открывает Steam Store, интерфейс Steam остаётся доступен.
- [ ] «Оцени аккаунт» открывает оригинальную страницу; при активном событии библиотека/инвентарь доступны. Если событие закончено, зафиксируйте сообщение сайта.
- [ ] Пополнение показывает текущий аккаунт, валюту, методы оплаты; касание суммы и A автоматически открывают клавиатуру, ввод сразу изменяет расчёт. После Enter/B управление возвращается к форме, подсвечен один элемент. Для проверки интерфейса платить не требуется.
- [ ] После «Оплатить» платёжная страница остаётся открытой. Для СБП проверьте QR провайдера. «Открыть страницу оплаты» возвращает к тому же заказу; B после возврата закрывает форму. Эта проверка создаёт заказ и выполняется только при намерении пополнить баланс.
- [ ] На странице игры с доступными предложениями они появляются внутри «Варианты покупки»: издание, регион, цена. Кнопка пополнения одна, закреплённого баннера нет. На странице без предложений нет неработающей кнопки покупки.
- [ ] B возвращает со страницы; повторное открытие каталога/пополнения работает.
- [ ] После сна/пробуждения и перезапуска Steam мост восстанавливается; лишних форм и кнопок нет.
- [ ] После смены аккаунта обновляется Steam ID; страна/валюта не берутся от прежнего аккаунта.
- [ ] Выключение плагина убирает его формы и внедрения; включение восстанавливает подключение.
- [ ] Удаление через Decky завершилось без оставшегося сервиса SteamBooster.

Оплата и активация требуют отдельной проверки с реальной операцией. Если операция завершилась таймаутом, сначала проверьте её статус в оригинальном сервисе; плагин автоматически её не повторяет.
