# Проверка v0.1.0

Дата: 2026-10-03.

- Python: 33 теста проходят, включая реальный локальный тестовый WebSocket, таймауты, закрытие, смену контекста, отказ при конфликте, выгрузку, изолированный импорт main.py и структуру ZIP.
- TypeScript/DOM: 10 тестов проходят. Проверены маршруты, адаптер окон, переход каталога в Steam Store, управление полями и запуск всех трёх оригинальных компонентов через адаптер Decky.
- TypeScript typecheck и Rollup build проходят.
- Framework с правкой диагностики: 875 тестов проходят, 23 пропущены, 0 ошибок.
- Python CDP подключился к работающему настольному Steam и отказался выбирать его в качестве контекста Decky до внедрения кода. Установленный Linux-сервис оставался активным.
- ZIP содержит один корневой каталог, обязательные файлы Decky, Python-код, оригинальные JS-компоненты и лицензии. Хеши компонентов и SHA256SUMS проверяются при сборке.

## Ещё не проверено

Физический Steam Deck, Game Mode в среде Decky Loader, сон/пробуждение и смена аккаунта на устройстве. Реальные оплаты и активация ключей. Полная отправка оценки при активном событии SteamBalance.

Выпуск помечен предварительным. Инструкции проверки устройства: device-test.md.
